# 📝 todo_ex_app (Haru Plan)

Team 3 Todo List App
  :  사용자가 할 일을 등록하고 관리할 수 있으며,
     카메라와 지도 기능을 함께 활용할 수 있도록 구현했습니다.

---

## 👥 Flutter Team Project

---

## ✨ 주요 기능

 - 로그인 화면
 -  Todo List 조회 및 관리
 -  새로운 할 일 추가
 -  오늘의 할 일 확인
 -  달성률 확인
 -  카메라 및 지도, 현재 위치 확인
 -  TabBar를 이용한 화면 전환
